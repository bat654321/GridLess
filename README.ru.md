# GridLess — бессеточный топологический трассировщик печатных плат

[English](README.md) | Русский

GridLess — автотрассировщик в духе TopoR для KiCad 10: сначала строится *топология*
(с какой стороны какого препятствия проходит каждый проводник), затем — точная геометрия
«резиновой нити»: отрезки под любыми углами и дуги вокруг площадок, концентрические пучки.

* ядро на Rust (`crates/gridless`), консольная утилита `gridless` (`crates/gridless-cli`);
* плагины KiCad 10: IPC API (kipy) и классический ActionPlugin (SWIG);
* дифференциальные пары, выравнивание длин (меандры), предпочтительные направления слоёв,
  минимизация переходных, автоматическое сужение трасс, плоскости (в т.ч. разделённые);
* выравнивание зазоров: проводники между близкими площадками идут посередине, пучки —
  с равными зазорами (с «радаром», ослабляющим правило для далеко стоящих площадок);
* встроенная проверка DRC и обратная связь «DRC → перекладка».

Почему так устроено и что взято из TopoR, Situs, SPECCTRA, Freerouting, Topola и др. —
см. [docs/ANALYSIS.md](docs/ANALYSIS.md). Полная справка о возможностях, алгоритмах и
параметрах — [docs/REFERENCE.ru.md](docs/REFERENCE.ru.md).

## Сборка

```bash
cargo build --release
```

Исполняемый файл: `target/release/gridless.exe`. Тесты: `cargo test --release`.

## Командная строка

```bash
gridless route board.kicad_pcb -o board_routed.kicad_pcb
```

| Ключ | Назначение |
|---|---|
| `-o FILE` | записать разведённую плату (исходник не меняется; неблокированные трассы заменяются) |
| `-c FILE` | файл настроек; по умолчанию `<board>.gridless.toml` рядом с платой |
| `--keep-existing` | оставить имеющиеся трассы и развести только недостающие соединения |
| `--kicad-check` | после трассировки залить зоны через `kicad-cli` и добавить переходные к плоскости для площадок, которые заливка не подключила; затем развести заново |
| `--rounds N` | число раундов «геометрия → DRC → перекладка» (по умолчанию 8) |
| `--png FILE [--view x0,y0,x1,y1 --scale K]` | картинка результата (нарушения — розовые точки) |
| `--json-out FILE` | результат в JSON (используется плагинами) |
| `--project FILE` | явный `.kicad_pro` с классами цепей |

`gridless info board.kicad_pcb` — сводка о плате.

## Настройки

Всё необязательно: по умолчанию берутся классы цепей и правила проекта KiCad,
дифпары определяются по суффиксам имён (как в KiCad: `_P/_N`, `+/-`, `P/N`),
внутренние слои, почти полностью залитые зонами, считаются плоскостями.
Полный пример с комментариями: [docs/example.gridless.toml](docs/example.gridless.toml).

```toml
[layers."F.Cu"]
direction = "horizontal"
[layers."B.Cu"]
direction = "vertical"

[[nets]]
match = ["+5", "3V3"]
width = 0.8            # в узких местах сужается автоматически

[[length_groups]]
match = ["DATA*"]
tolerance = 0.5

[[diff_pairs]]
p = "USB_P"
n = "USB_N"
max_skew = 0.1
```

### Выравнивание зазоров («радар»)

Резиновая нить прижимает проводники к площадкам — так короче. Последний шаг постобработки
разводит их: если проводник проходит между двумя площадками (любой формы, а также
переходными), он идёт посередине; если проводников несколько — зазоры
«площадка – проводник – … – проводник – площадка» одинаковы. Правила зазоров при этом
главнее: каждый зазор не меньше своего правила (с учётом классов цепей обеих сторон),
а равными делаются остальные — то, что остаётся сверх правил. Где проводник огибает
площадку, он делает это одной дугой через середины зазоров, без изломов.

«Радар» смотрит на расстояние между самими площадками (медь — медь): до `full` проводники
стоят строго посередине, дальше влияние плавно слабеет и на `range` исчезает — площадки,
стоящие далеко друг от друга, проводник не тянут.

```toml
[centering]
enabled = true   # по умолчанию включено
full = 1.3       # мм; по умолчанию 2 «канала» (ширина дорожки + 2 зазора класса Default)
range = 3.25     # мм; по умолчанию 5 каналов
```

Топология, переходные и выравнивание длин не меняются (длины выравниваются уже после).
Если на каком-то слое выравнивание добавило бы нарушений DRC, на этом слое остаётся
прежняя геометрия. На плате Carrier шаг занимает ≈ 1 с и удлиняет трассы на ≈ 0,8 %.

### Сглаживание

Следом идёт сглаживание: вход в площадку становится прямым (короткий «хвостик» выхода из
площадки поглощается, если трасса может зайти в площадку напрямую, не дальше 2 мм и
с поворотом на стыке не больше 60°), а оставшиеся изломы скругляются дугами с прогибом
не больше 0,05 мм. Каждое изменение проверяется на зазоры; дифпары не трогаются. Как и у
выравнивания зазоров, слой, на котором шаг добавил бы нарушений DRC, остаётся прежним.

### Резерв длины под меандры

Как в TopoR, место под меандры выравнивания длин можно оставить ещё на этапе топологии:
короткие проводники группы прокладываются как более широкие (на ширину будущего
меандра), и соседние трассы не занимают нужный им коридор.

```toml
length_reserve = "auto"   # по умолчанию; также "always" и "off" (ключ верхнего уровня)
```

В режиме `auto` плата сначала разводится без резерва; если какой-то проводник группы
длин не добрал длину, трассировка повторяется с резервом и остаётся лучший из двух
результатов. Резерв не меняет ни зазоров, ни итоговой ширины проводников.

### Переходные дифпар

Переходные дифференциальной пары ставятся рядом, поперёк направления пары, с шагом
`max(ширина + зазор пары, диаметр переходного + зазор)`, а не там, где удобно каждому
проводнику по отдельности.

## Плагин KiCad 10

### Установка через PCM (рекомендуется)

1. Скачайте `gridless-<версия>-pcm.zip` со страницы
   [Releases](https://github.com/bat654321/GridLess/releases).
2. В KiCad: **Инструменты → Менеджер плагинов и контента → Установить из файла…**
3. Когда KiCad предложит включить API-сервер, согласитесь (или включите позже:
   **Настройки → Плагины → Включить KiCad API**).
4. Откройте редактор печатных плат и нажмите кнопку **GridLess**.
   При первом запуске KiCad создаёт окружение Python и ставит `kicad-python` —
   это может занять минуту.

Пакет использует IPC API: он трассирует открытую плату **вместе с несохранёнными
правками** и вставляет результат одним шагом отмены. На macOS бинарник подписан
ad-hoc; если Gatekeeper его блокирует, разрешите запуск в
**Системные настройки → Конфиденциальность и безопасность**.

Диалоги плагина используют wxWidgets. В Python, который поставляется с KiCad для
Windows и macOS, он есть. В Linux внешний Python, выбранный KiCad, может быть без
wxWidgets; тогда плагин всё равно трассирует с настройками по умолчанию и печатает
отчёт. Поставьте `wxPython`, если нужны диалоги, или используйте классический
плагин.

### Сторонний PCM-репозиторий (уже доступен)

Пакет также лежит в небольшом репозитории на GitHub Pages, поэтому его можно
ставить и обновлять через PCM, не дожидаясь официального каталога. В
**Инструменты → Менеджер плагинов и контента → Управление репозиториями** добавьте:

```
https://bat654321.github.io/GridLess/repository.json
```

После этого GridLess появится в списке пакетов. Заявка в официальный каталог
открыта: [kicad/addons/metadata!759](https://gitlab.com/kicad/addons/metadata/-/merge_requests/759).

### Ручная установка (оба плагина)

```bash
cargo build --release
python kicad_plugin/install.py
```

Установщик кладёт в `Documents/KiCad/10.0`:

* `scripting/plugins/gridless_swig` — ActionPlugin (SWIG). Работает сразу:
  *Инструменты → Внешние модули → GridLess: трассировка* (или кнопка на панели).
  Трассирует **сохранённый** файл платы — сохраните плату перед запуском.
* `plugins/gridless` — плагин IPC API (kipy). Берёт плату вместе с несохранёнными
  правками и вставляет результат одним шагом отмены. Требует
  *Настройки → Плагины → Включить KiCad API*; зависимость `kicad-python` KiCad ставит сам.

Оба плагина спрашивают, оставлять ли существующие трассы и сколько раундов делать.
Во время трассировки открыто окно хода работы: текущий этап (топология, геометрия,
раунды DRC с числом нарушений, доводка, выравнивание длин; с проверкой заливок —
«проход 1 из 2» и «проход 2 из 2»), шкала, время и живой журнал трассировщика.
Кнопка **Cancel** останавливает трассировщик (вместе с запущенным им `kicad-cli`) —
плата остаётся как была. При ошибке окно не закрывается, чтобы журнал можно было
прочитать. После трассировки показывается отчёт (переходные, длина, DRC, выравнивание
длин); после вставки нажмите **B**, чтобы перезалить зоны.

### Язык интерфейса

Плагин берёт язык из **Настройки → Общие → Язык** и, если там стоит *Default*,
использует язык операционной системы. Переведены все 44 языка, доступные в
KiCad 10, включая русский и украинский. Переводы — первые версии (готовились с
помощью ИИ); носители языка могут улучшить их: каждый язык — один JSON-файл в
`kicad_plugin/common/locales/`, после правки запустите
`python kicad_plugin/check_i18n.py`. Переменная `GRIDLESS_LANG=ru` (или код/название
языка KiCad) переопределяет определение языка при тестировании. Живой журнал
трассировщика в окне прогресса остаётся на английском: это диагностический вывод
Rust-программы, а не часть интерфейса.

## Результаты на тестовых платах

Плата **Carrier** (4 слоя, In1 — GND, 43 компонента, 281 площадка, 75 цепей), сравнение
с ручной разводкой. Питание (+5, 3V3, 3V7) — 0,8 мм; группа длин A/B/C_DATA; дифпара USB.
DRC — проверка самого KiCad 10 (`kicad-cli pcb drc --refill-zones`); трассировка с `--kicad-check`.

| | Ручная разводка | GridLess |
|---|---|---|
| Ошибки зазоров / замыкания / пересечения | 0 | 0 |
| Переходные отверстия | 30 | 28 (23 без файла настроек) |
| Длина трасс | 1330 мм | 1286 мм (вкл. меандры) |
| Острые углы (< 120°) | — | 0 |
| Неподключённые элементы | 1 | 4 (островки заливки GND) |
| «Голодные» термобарьеры | 3 | 4 |
| Время | — | ≈ 11 с (≈ 4 с без `--kicad-check`) |

Плата **Beacon** (BLE-модуль Ø22 мм, QFN 0,4 мм, разделённая плоскость питания) пока
разводится не полностью: ≈ 12 нарушений и 3 неподключённые цепи в RF-узле (см. ниже).

## Ограничения и планы

* Дифпары: перекос P/N считается по всему пути пары через промежуточные компоненты
  (разъём → ESD → МК) и компенсируется только на более коротком проводнике; мостики между
  дублирующими выводами одного корпуса (USB-C A6/B6) в путь не входят.
* Выравнивание длин только меандрами на прямых участках; если места нет даже с резервом
  длины — сообщается «NOT MET».
* Предпочтительные направления влияют на выбор слоя и коридора, но финальная «резиновая
  нить» изотропна (кратчайшая) — диагонали остаются. Планируется анизотропная метрика.
* Плотные корпуса с шагом 0,4 мм и RF-узлы (антенна в запретной зоне) — требуют доработки
  шаблонов выхода из площадок и правил исключений для запретных зон.
* Островки медной заливки не сшиваются автоматически переходными.
* Параллельные прогоны на нескольких ядрах CPU с выбором лучшего (архив вариантов) — следующий шаг;
  GPU для плат этого класса не даёт выигрыша (обоснование в docs/ANALYSIS.md).

## Структура

```
crates/gridless/src/
  kicad.rs      чтение .kicad_pcb/.kicad_pro, запись трасс
  config.rs     настройки и итоговые правила
  problem.rs    препятствия, места переходных, план соединений
  mesh.rs       ограниченная триангуляция Делоне по слоям
  topo.rs       топологический трассировщик (A*, переговоры, rip-up, переходные)
  geometry.rs   геометрия резиновой нити, дуги, сужения, дифпары, выравнивание зазоров
  smooth.rs     сглаживание: прямые входы в площадки, скругление изломов
  tuning.rs     меандры, перекос дифпар, резерв длины
  drc.rs        собственная проверка правил
  pipeline.rs   полный цикл с обратной связью DRC
kicad_plugin/   плагины KiCad и установщик
docs/           анализ аналогов, пример настроек, статьи (docs/articles)
```
