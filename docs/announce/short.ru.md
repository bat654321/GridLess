# Короткие тексты для русскоязычных площадок

## Telegram / Mastodon

GridLess — бессеточный топологический автотрассировщик для #KiCad 10: любые
углы, дуги вокруг площадок, дифпары, выравнивание длин. На 4-слойной тестовой
плате — 0 нарушений зазоров, 28 переходных против 30 при ручной разводке, ~11 с.
MIT, интерфейс на всех 44 языках KiCad. Плотные QFN 0,4 мм и RF пока даются
плохо — это следующий шаг. https://github.com/bat654321/GridLess
